# Storyforge Knowledge

Reusable production knowledge captured from approved Storyforge results.

Use `knowledge_capture` with `scope: "global"` or `scope: "both"` to add cards
under `knowledge/cards/`.

Project-specific knowledge belongs under:

```text
projects/<project-id>/wiki/cards/
```

Global knowledge should only contain patterns that are useful across projects,
such as shot grammar, style recipes, physical-action decomposition, prompt
templates, and known failure cases.
