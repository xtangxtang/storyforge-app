# 连续动作合成一镜，不要拆成独立镜再拼

- scope: global
- type: editing_grammar
- tags: editing, cut, continuity, one-shot, collision, hard-contact, atomic, aftermath
- captured_at: 2026-06-09

## Summary

硬切（cut）只适合**不连续**的地方：时间跳跃、换地点、为新 beat 换全新机位。而**动作连续、中间没有断点**的相邻 beat（如「骑车冲来 → 相撞 → 道歉」全程同一人在动），若拆成多条独立生成的视频再拼接，机位与姿态对不上、接缝突兀。正解是**做成一条连续镜头**（t2v / i2v 单条最长 10s，足够一个微场景）。这同时修正了把剧情过度拆成大量原子镜的毛病。

## When To Use

- 分镜 / 原子镜拆分时；决定一个动作段是一条镜还是多条时

## Do

- 动作连续的一段（逼近 → 接触 → 余波）做成一条连续镜，一次生成
- 只在真正的断点切镜：时间跳、换地点、为强调换全新机位、或一条放不下（> 10s）
- 硬接触（相撞 / 急刹）放在连续镜里，接触那一下靠运动模糊 + 余波带过（模型给不出精确接触帧）
- 余波用中近景收（道歉 / 反应），让情绪可读
- 用身份锚点区分同框角色（如戴眼镜 vs 不戴、有无书包），避免谁撞谁错乱
- 困难动作的站位要真实：横切来的人从侧巷汇入、与主体路线交汇，而不是傻站在路中间被追尾

## Avoid

- 把「骑车」和「骑车撞人」拆成两条再拼（双重骑行 + 硬切，既冗余又跳）
- 为每个微动作单开一条镜（过度原子化，反而更难连）
- 跨连续动作做硬切（姿态 / 机位对不上）

## Prompt Patterns

- 一条镜内分段叙述：「开头：<A 动作>；接着：<B 入画>；然后：<接触>；最后：镜头收成中近景<余波>」

## Examples

- 开场把 AS002（骑行）+ AS003（相撞）+ AS004（道歉）合成一条 opening_whole，无接缝，比三条拼接自然
- 相撞站位：俞墨凡从右侧小巷朝校门汇入、横切到车前被撞，比「站路中间被追尾」自然
