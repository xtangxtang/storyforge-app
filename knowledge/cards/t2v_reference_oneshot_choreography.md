# t2v 参考模式一镜到底：AS004 五版迭代换来的成片配方

- scope: global
- type: shot_grammar
- tags: seedance, t2v, reference_image, one-shot, camera-path, anti-jumpcut, consistency
- captured_at: 2026-06-11

## Summary

AS004（扶车→骑行→超越俞墨凡→双双入校门）经历 5 版才成片。失败原因依次是：
i2v 只吃首帧导致中段校门/俞墨凡漂移 → API 禁止 first_frame 混参考媒体 → t2v 成片但跳切、绕开校门、
校门照搬参考图呆板。最终配方 = **t2v 参考模式 + 三类参考图 + 显式连续运镜路径 + 反照搬条款 + 元素提前入画**。

## Do（按重要性排序）

1. **模式选择**：镜头中段才出现新人物/新地点（不在首帧里）→ 直接走 t2v 参考模式，
   refs=【本镜无脸首帧图(锁构图与方向) + 地点 canon(锁建筑) + 角色定妆图(锁身份)】，cap 3。
   不要先试 i2v 再补救——first_frame 与 reference 媒体互斥是 API 硬限制。
2. **防跳切三件套**：①开头声明"一镜到底、无任何剪切跳跃的连续镜头"；
   ②让后续要用到的元素**尽早进入画面深处并一直留在画面里**（"镜头拉开后，虚化的校门与俞墨凡背影始终留在画面深处"）——
   元素不在画面里，模型就会用跳切把它"剪进来"；
   ③写出**物理连续的镜头路径**，每次机位变化都有过渡动词：上移→拉开升高→环绕到身后→跟随→停住目送。
3. **反照搬条款**（参考图防呆板/防贴图）："<地点>只作为远处真实环境呈现：角度、距离、景深与透视随镜头运动自然变化，
   融入空间，绝不照搬参考图的固定构图、不是静止贴图或海报式背景。"
   ——不写这句，canon 参考图会被原样贴进画面，呆板且透视错。
4. **镜内情绪节拍**：t2v 没有输入帧审核，可以编排"无脸起幅→动作转折瞬间镜头上移露脸给情绪特写"
   （"直起身的瞬间，镜头自然上移给到他的脸——神情焦急、咬着牙赶时间"）。美学上保留无脸开场，情绪上不缺正脸。
5. **节拍↔时长**：每个动作/运镜节拍约 1.5-2 秒；加一拍（如露脸）就加 1 秒时长，否则赶戏出跳切。
6. **中段人物文字写全**：即便有定妆图作参考，video_prompt 里仍要写全外观
   （"同款白色Polo深蓝条纹校服、深蓝长裤、戴黑色头戴耳机、背深蓝双肩书包"）——图锁脸，字锁衣。

## Avoid

- i2v 镜里指望中段出现的人物/地点"自己长对"——没有任何参考可挂，必漂移
- 元素只在结尾才被提到（"此时画面深处显现…"且前文不在画面里）——必跳切
- 只写机位结果不写过渡（"镜头停住看着…"前面没有"跟随/环绕"路径）——机位瞬移
- 参考视频用本地文件/base64（reference_video 只收 web URL，需渲染后 24h 内的 TOS video_url）
- 过度约束动线（"必须从门洞正中穿过、绝不绕开"）——模型会为满足字面约束生成僵硬路径；写"骑入敞开的校门"即可

## Prompt Patterns

- 运镜骨架：「起幅<低角度/特写>（看不到脸）→<动作转折>瞬间镜头自然上移给到<角色>的脸——<情绪>→
  镜头顺势拉开并升高并环绕到<角色>身后跟随，画面深处显现虚化的<地点>与<人物背影>→
  镜头跟随<角色>前进、逐渐接近→随后镜头停住、固定机位目送<结局动作>」
- 反照搬：「<地点>只作为远处真实环境呈现：角度/距离/景深/透视随镜头运动自然变化，绝不照搬参考图固定构图」
- 收尾恒句：「全程单镜连续，<元素们>从镜头拉开后始终留在画面深处自然过渡、无跳切」
