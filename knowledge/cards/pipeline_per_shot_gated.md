# 逐 stage、逐分镜门控生成，不一口气批量出全片

用户(2026-06 风起乒乓少年项目起)明确要求:流水线不要一次性把所有分镜/首帧/视频全生成,
而是**一个 stage 一个 stage、一个分镜一个分镜推进**,每一步产物先给用户审,
**用户同意后才做下一步**(下一张首帧、下一条视频、下一个分镜)。

## Do

- 单镜推进:改文档 → 出首帧 → 用户确认首帧 → 渲视频 → 用户确认成片 → 才进入下一镜
- 每次只动当前分镜的 03/04/05/06 字段,保持四文档与实际产物一致
- 首帧/视频被否后只重做当前这一步,不顺带跑后面的镜头

## Avoid

- "批量渲染剩余全部镜头"式的一次性收尾(除非用户明确要求批量)
- 在用户未确认当前镜产物时,预先生成后续镜头的首帧或视频
- 在 storyboard 层批量铺出大量后续分镜——分镜也按需逐个定稿
