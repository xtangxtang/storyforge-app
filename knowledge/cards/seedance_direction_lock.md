# Seedance 图生视频方向锁定（背影/过肩首帧）

- captured_at: 2026-06-08

## Summary

控制 Seedance 图生视频里人物/镜头的运动方向，最可靠的手段是首帧用「背影或过肩、把运动目的地放在画面纵深」的构图，而不是给视频喂参考图。相机在主体背后、目标（校门/讲台/对方）在景深处时，模型只能「朝纵深走/驶/看」，方向天然被锁住。给视频生成喂静态正面参考图会把相机拽成正面，人物反而朝镜头或朝外走。

## When To Use

- 任何「必须朝某方向运动 / 进入 / 相撞 / 到达」的镜头
- 开场骑车进校门、走进教室、转身打招呼、两人相遇相撞

## Do

- 首帧用纯背影或过肩，相机在主体后方，运动目的地置于画面深处
- 方向只用相机相对语言（「背对镜头朝画面深处的校门」「由近及远」）
- 用首帧单帧驱动（first-frame-only），让模型自由生成自然前进运动
- 困难动作（相撞、急刹、转向）拆成多条短镜 + 切镜 / 反应镜

## Avoid

- 给「视频生成」喂参考图或参考视频来定方向（静态正面参考把相机拽正、人物朝外走，"参考图害人"）
- 首帧 + 尾帧一起喂：首尾差异大时会 morph（窗变教室、人物 pop-in）
- 贴镜头大正脸做首帧（既不锁方向又容易触发审核）

## Prompt Patterns

- 「低角度全景，画面深处正前方是<目的地>；<角色>纯背影（看不见正脸）<动作>朝画面深处<目的地>方向」
- 「过肩中近景，机位越过<角色A>的后脑勺与肩膀（看不到正脸）看向<角色B>」

## Examples

- 陈振飞骑车进校门：背影首帧（车从右后入画、校门在景深）→ first-frame i2v → 相撞发生在门口而非门外
- t2v / 正面参考图版本：开场骑车方向起反、相撞跑到校门外
