# t2v 双人碰撞镜：身份/书包/地点不漂的参考图与硬约束配方

- scope: global
- type: shot_grammar
- tags: seedance, t2v, reference_image, multi-character, collision, identity-lock, anti-duplicate, anti-faceswap
- captured_at: 2026-06-12

## Summary

AS003（俞墨凡背影入场→陈振飞从左后骑车追撞→道歉→俞墨凡走向校门）是固定机位双人碰撞镜，
迭代十余版才稳。t2v 双人同框 + 碰撞乱镜会同时引爆四类漂移：①配角书包出不来 ②角色被复制成两个
③碰撞峰值两人脸/眼镜互串 ④地点（校门）被模型瞎编成"大学拱门带字"。
配方 = **每个独占特征都要有自己的参考图（含无脸背面图） + 防复制/防互串/锁特征三条硬约束 + 用地点 canon 重做构图锚点首帧**。

## Do

1. **独占道具用"无脸背面参考图"锁，别只靠文字**：陈/俞同款校服，仅靠 video_prompt 写"背深蓝/深灰书包"
   出不来或串色。给每人单独生成一张【纯背面、看不到脸、书包为主体】的参考图（`俞墨凡_背面书包.png` 深蓝、
   `陈振飞_背面书包.png` 深灰），书包立刻稳定且两人背影可区分。纯背面无脸 → 还能躲过 PrivacyInformation 审核。
2. **同款人物给不同颜色独占物**：两人都白Polo深蓝裤时，靠"陈=深灰包+黑框眼镜 / 俞=深蓝包+头戴耳机"区分；
   颜色写进 canon（recurring_props 拆成 书包(陈)/书包(俞)）并在每帧硬锁。
3. **防角色复制硬约束**：双方各带一张正脸定妆图时，碰撞乱镜里模型会把"前脸版"和"背影版"实例化成两个同人。
   加：「全片有且仅有 A、B 两个明确人物；绝不出现第二个 A 或第二个 B；背景同学一律远处、极度虚化、面目模糊、
   不戴<独占配饰>、绝不与主角雷同。」复制立刻收敛。
4. **防脸/特征互串硬约束**：碰撞峰值（实测 AS003 第 4–5 秒）模型会把 A 的眼镜错戴到 B 脸上。加：
   「任何一帧：A 始终戴黑框眼镜不戴耳机；B 始终戴耳机绝不戴眼镜；冲撞/摔倒/爬起/靠近全程，脸与眼镜耳机
   绝不张冠李戴或互换；两人始终是两张不同的脸。」
5. **地点靠 canon 重做锚点首帧，别让模型自由发挥**：构图锚点首帧若地点不明确，t2v 会瞎编（AS003 编出"大学"拱门带字）。
   用地点空镜 canon（`茅盾中学门口_空镜低位.png`，无字）+ 配角无脸背面图重新生成 `<shot>_first.png`，
   把"虚化的对的门 + 配角背影 + 书包"一次锚进首帧；renders 引用此首帧即不再漂。
6. **入场方向写"相对镜头的近/远"**：要"A 从后方追撞 B"，必须写「A 从画面左后方的近处（镜头这一侧、B 的背后）
   冲入，绝不是从画面深处的<地点>方向迎面骑出」——否则模型让追撞者从背景地点迎面开过来。
7. **ref 槽位（实测 cap≥4）**：[构图锚点首帧, A定妆脸, A背面书包, B定妆脸] 4 张可过提交校验。
   配角书包已在锚点首帧里时，可不再单列其背面书包图，给正脸定妆图让位。

## Avoid

- 配角书包只在 video_prompt 写文字、不给背面参考图 → 出不来或串成主角的包色
- 两张正脸定妆图 + "零散同学"且不加防复制条款 → 背景同学被套上主角脸 / 主角被克隆成两个
- 构图锚点首帧地点含可读文字或不明确 → 成片牌匾文字漏出、或被编成别的门
- 正脸/侧脸参考图易触发 `PrivacyInformation` 400（非确定性）：纯背面图最稳；正脸图就靠重试（400 不计费），见 [[ark-quota-probe-cost]]
- 固定机位镜里又写"镜头推近"：二者矛盾，推镜会非确定性变弱；要特写就别同时声明"全程固定机位…构图不变"
